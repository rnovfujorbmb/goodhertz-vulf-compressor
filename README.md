## Overview

Goodhertz Vulf Compressor is a character compressor modeled on the pumping, punchy sound of vintage funk recordings, adding rhythmic groove and lo-fi warmth to any signal.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Goodhertz Vulf Compressor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Pump Character** | Deliberate compression pumping for the classic funk/soul groove effect |
| **Saturation** | Warm soft-clip saturation matching vintage console coloration |
| **Mix Knob** | Parallel wet/dry blend for controlling the intensity of the effect |
| **Simplicity** | Just four controls for fast, musical results without menu diving |
